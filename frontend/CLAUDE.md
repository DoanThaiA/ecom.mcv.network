## Quick Reference

### Tech Stack
- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS (no inline styles)
- **UI Components**: Radix UI (`@radix-ui/themes`)
- **Icons**: Radix Icons (`@radix-ui/react-icons`)
- **State Management**: Redux Toolkit + Redux Saga
- **i18n**: next-intl

### Common Commands
```bash
npm run dev          # Start development server
npm run build        # Build for production
npm run lint         # Run ESLint (required before commit)
npm run lint:fix     # Auto-fix lint issues
```

### Key Directories
```
/app                 # Next.js App Router pages
/components          # Reusable UI components
/lib
  /config            # App configuration (API_BASE_URL)
  /helpers           # Helper functions (toastHelper)
  /services          # Services (storageService)
  /store             # Redux store, slices, sagas
  /utils             # Utility functions (format, dialog)
  /repositories      # API repositories
/messages            # i18n translations (en.json, vi.json)
/types               # TypeScript type definitions
```

### Critical Rules Summary
1. **i18n**: Use `t('key')` - never hardcode text
2. **Styling**: Tailwind only - no inline styles
3. **UI Components**: Use Radix UI (`Box`, `Flex`, `Text`, `Button`...) - NEVER use HTML tags (`<div>`, `<span>`, `<button>`)
4. **Toast**: Use `toastHelper` - not `sonner` directly
5. **Storage**: Use `storageService` - not `localStorage` directly
6. **Format**: Use `@/lib/utils/format` for numbers/dates
7. **API URL**: Import `API_BASE_URL` from `@/lib/config/api`
8. **File size**: Max 500 lines per file
9. **Version**: Update both `version.json` and `VERSION.md` after each task

### Planning Mode
Khi lên kế hoạch (plan) cho một task:
1. **Tạo file plan**: Lưu plan thành file `.md` trong thư mục `/plans`
2. **Đặt tên file**: Sử dụng tên mô tả ngắn gọn, ví dụ: `feature-login.md`, `fix-cart-bug.md`
3. **Nội dung plan**: Bao gồm mục tiêu, các bước thực hiện, và các file cần thay đổi

### Before Committing
1. Run `npm run lint` and fix all errors
2. Update `version.json` and `VERSION.md`
3. Ensure no hardcoded text (use i18n)
